# DocuMind Visual Assets & Architecture Gallery

This directory contains architectural visual diagrams and UI screenshots for DocuMind:

- `architecture.png`: End-to-end RAG architecture diagram.
- `upload.png`: Streamlit document upload and indexing interface.
- `chat.png`: Grounded question-answering session showing verified citations.
- `retrieval.png`: FastAPI Swagger UI demonstrating `/retrieve` similarity scores.

> **Note for Contributors:**
> When adding new screenshots, please capture the application running at `http://localhost:8501` and save images at 1920x1080 resolution in PNG format.
